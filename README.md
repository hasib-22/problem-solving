## How to use

- Open `solution.js` in VS Code or any JavaScript editor.
- Read the problem section you want.
- Paste a function into a Node or browser console, or add a quick test snippet at the end of the file.

Example:

```js
console.log(staircase(4));
console.log(gradingStudents([73, 67, 38, 33]));
```

## Notes

- This is a practice collection, not a full project with dependencies.
- No install step is required unless you want to run it in a JavaScript runtime.
